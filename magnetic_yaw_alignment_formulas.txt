改进后的磁力计初始航向估计算法
================================

1. 当前代码的核心公式

          ψ = atan2(mˡᵧ, mˡₓ)

按照当前 FRD/NED 定义，应改为

          ψ = wrap₍₋π,π₎ [ δᴰ - atan2(mˡᵧ, mˡₓ) + δⁱⁿˢᵗᵃˡˡ ]

其中

          δᴰ       ：当地磁偏角
          δⁱⁿˢᵗᵃˡˡ：磁力计相对 IMU 的剩余航向安装偏角

----------------------------------------------------------------
2. 磁力计标定模型

          mᵇₖ = Cᵇₘ Sₘ (mʳᵃʷ,ᵐₖ - bₘ)

其中

          mʳᵃʷ,ᵐₖ：第 k 帧原始磁力计测量
          bₘ      ：硬铁偏置向量
          Sₘ      ：软铁与比例因子校正矩阵
          Cᵇₘ     ：磁力计坐标系到 IMU 机体系的安装矩阵
          mᵇₖ     ：标定后、位于 IMU 机体系中的磁场向量

----------------------------------------------------------------
3. 静止性与磁场模长检查

          | ‖fₖ‖ - g | < εₐ

          ‖ωₖ - median(ω)‖ < εω

          rₖ = ‖mᵇₖ‖

          r̂ = median(rₖ)

          MADᵣ = 1.4826 median(|rₖ-r̂|)

          |rₖ-r̂| ≤ κ MADᵣ

----------------------------------------------------------------
4. 使用有效加速度样本估计横滚角和俯仰角

          f̄ = RobustMean(fₖ)

          ϕ = atan2(-f̄ᵧ, -f̄_z)

                         f̄ₓ
          θ = atan2(───────────────)
                    √(f̄ᵧ² + f̄_z²)

----------------------------------------------------------------
5. 对每个有效磁场样本进行倾斜补偿

          mˡₖ = Rᵧ(θ) Rₓ(ϕ) mᵇₖ

          mˡₓ,ₖ = mᵇₓ,ₖ cosθ
                 + mᵇᵧ,ₖ sinϕ sinθ
                 + mᵇ_z,ₖ cosϕ sinθ

          mˡᵧ,ₖ = mᵇᵧ,ₖ cosϕ - mᵇ_z,ₖ sinϕ

----------------------------------------------------------------
6. 按 FRD/NED 约定计算每帧真北航向

          αₖ = atan2(mˡᵧ,ₖ, mˡₓ,ₖ)

          ψₖ = wrap₍₋π,π₎(δᴰ - αₖ + δⁱⁿˢᵗᵃˡˡ)

----------------------------------------------------------------
7. 对航向进行加权圆周均值

                 N
          C  =   Σ  wₖ cos(ψₖ)
                k=1

                 N
          S  =   Σ  wₖ sin(ψₖ)
                k=1

          ψ̂ₘₐg = atan2(S, C)

不能直接计算 (ψ₁ + ψ₂ + ... + ψᴺ) / N，
因为航向角在 -180° 与 +180° 处存在环绕。

----------------------------------------------------------------
8. 圆周集中度和圆周标准差

                 √(C² + S²)
          R  =  ─────────────
                   N
                   Σ wₖ
                  k=1

          σψ = √[-2 ln(R)]

其中

          R → 1：各帧航向高度集中，磁航向稳定
          R → 0：各帧航向分散，磁航向不可信
          σψ    ：圆周标准差，数值越小越可信

----------------------------------------------------------------
9. 最终采用条件

          N ≥ Nₘᵢₙ  且  σψ < σₘₐₓ  且  ηᵥₐₗᵢd > ηₘᵢₙ

                ⎧ ψ̂ₘₐg       条件满足
          ψ₀ =  ⎨
                ⎩ ψcoarse    条件不满足
